## Запуск

### Установка

Вставьте в терминал команду:
```
git clone https://github.com/Tamik13/secure_stack
```

Все нужные файлы скопируются в текущую папку

### Компиляция

Для компиляции программы введите команду

```
compile
```
> работает только на маке/линуксе

### Запуск

Введите команду

```
 ./onegin_srt
```
> работает только на маке/линуксе

## Фишки

* Канареечная защита
* Кэширование массива и структуры
* В функции stack_verify множество проверок
* stack не ложит программу а просто возвращает код ошибки
* Подробный вывод в log файл
